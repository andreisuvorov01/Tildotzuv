# Статус поддержки площадок для государственных закупок

## ✅ Полностью поддерживаемые площадки

### 1. zakupki.gov.ru
- **Статус**: ✅ Работает
- **Метод**: Request-based парсер
- **URL**: `https://zakupki.gov.ru/epz/order/extendedsearch/results.html`
- **Фильтры**: Полная поддержка (поиск, сортировка, диапазоны)
- **Результат**: 10+ закупок за ~2 секунды

## 🔄 Площадки в разработке

### 2. Сбербанк-АСТ (sberbank-ast.ru)
- **Статус**: 🔄 Selenium интегрирован
- **Проблема**: JavaScript challenge защита
- **URL**: `https://www.sberbank-ast.ru/UnitedPurchaseList.aspx`
- **Текущее состояние**: Selenium WebDriver настроен, требуется оптимизация производительности
- **Технологии**: Selenium + ChromeDriverManager + headless Chrome

### 3. Росэлторг (roseltorg.ru)
- **Статус**: ✅ Работает
- **Метод**: Request-based парсер
- **URL**: `https://www.roseltorg.ru/procedures/search?sale=1&status%5B%5D=5&status%5B%5D=0&status%5B%5D=1&currency=all&place=fkr&source%5B%5D=13&page=1`
- **Результат**: 10+ процедур с номерами и ценами
- **Особенности**: Извлекает данные из текста элементов

### 4. РТС-тендер (rts-tender.ru)
- **Статус**: 🚀 Многоуровневый обход Cloudflare
- **Проблема**: Anti-DDoS защита Cloudflare
- **URL**: `https://www.rts-tender.ru/poisk/poisk-44-fz?keywords=`
- **Текущее состояние**: 3 стратегии обхода + Selenium + undetected-chromedriver
- **Особенности**: undetected-chromedriver, cloudscraper, advanced Selenium
- **Технологии**: Multi-strategy bypass с fallback механизмами

### 5. НЭП (neptek.ru)
- **Статус**: 🔄 Проблемы с HTTPS
- **Проблема**: SSL/TLS handshake failed
- **URL**: `https://neptek.ru/trades`
- **Текущее состояние**: Проблемы с безопасным соединением

## 🛠 Технические особенности

### Request-based парсеры
- ✅ Быстрые (2-3 секунды)
- ✅ Экономичные (без браузера)
- ❌ Не работают с JavaScript-защитами
- ❌ Не обрабатывают динамический контент

### Браузерные парсеры
- ✅ Обходят JavaScript защиты
- ✅ Обрабатывают динамический контент
- ❌ Медленнее (10-30 секунд)
- ❌ Требуют больше ресурсов
