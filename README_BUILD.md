# Улучшенный процесс сборки Docker-контейнера

## Оптимизации, реализованные в проекте:

### 1. Исправление конфигурации зависимостей
- Удалено дублирование зависимости `cloudscraper` в `pyproject.toml`
- Обновлена версия cloudscraper до `^1.2.72` (корректная доступная версия)
- Добавлены новые зависимости для обхода антибот-защиты:
  - `curl_cffi` для имитации TLS-отпечатков (JA4)
  - `nodriver` для улучшенной браузерной автоматизации
  - `capsolver` для решения капчи
  - `seleniumbase` для UC Mode с встроенными методами обхода
  - `drissionpage` для комбинированного подхода (браузер + HTTP)
  - `patchright` для улучшенной защиты от CDP-детекции
  - `tls-client` для имитации TLS-handshake реальных браузеров
- Обновлена структура файла зависимостей для лучшей совместимости

### 2. Оптимизация Docker-сборки
- Добавлены переменные окружения для избежания интерактивных запросов во время сборки:
  ```dockerfile
  ENV DEBIAN_FRONTEND=noninteractive
  ENV TZ=Etc/UTC
  ```
- Полный набор системных зависимостей, необходимых для работы приложения:
  - `curl`, `wget`, `dnsutils`, `iputils-ping` - для сетевой диагностики и скачивания
  - `gnupg` - для проверки подписей пакетов
  - `google-chrome-stable` - для работы Selenium и Playwright
  - `tor` - для обхода блокировок
  - Компиляторы и библиотеки (`build-essential`, `libssl-dev`, и др.) - для установки Python пакетов
- Изменена установка зависимостей через Poetry для корректной работы:
  ```dockerfile
  RUN poetry config virtualenvs.create false && \
      poetry install --no-interaction --no-ansi --no-root --only=main
  ```

### 3. Улучшение производительности при работе с cloudscraper
- Добавлен глобальный импорт cloudscraper в начале файла `app/services/scraper_engine.py`
- Реализован контроль доступности библиотеки перед использованием
- Добавлена обработка случаев, когда cloudscraper недоступен
- Создан метод `_run_enhanced_cloudscraper_parser` с улучшенными настройками для обхода усиленной защиты Cloudflare
- Улучшена логика обработки RTS-Tender с несколькими стратегиями обхода защиты

### 4. Современные методы обхода антибот-защиты

#### 4.1. Браузерная автоматизация
- **Nodriver** — официальный преемник undetected-chromedriver. Управляет Chrome напрямую через протокол CDP (DevTools), не оставляя следов WebDriver, что делает его крайне сложным для обнаружения
- **SeleniumBase (UC Mode)** — мощный фреймворк, включающий режим Undetected-Chromedriver. Автоматически переименовывает переменные автоматизации и имеет встроенные методы для обработки капч
- **Camoufox** — антидетект-браузер на базе Firefox. Подменяет цифровые отпечатки на уровне C++, обеспечивая нулевой уровень детекции
- **DrissionPage** — легковесная альтернатива, сочетающая возможности браузерной автоматизации и прямых HTTP-запросов
- **Patchright** — форк Playwright, специально разработанный для устранения утечек CDP, которые выдают использование инструментов автоматизации

#### 4.2. HTTP-клиенты (Имитация отпечатков TLS/JA4)
- **curl_cffi** — библиотека, использующая curl-impersonate. Имитирует отпечатки TLS (JA3/JA4) и HTTP/2 популярных браузеров (Chrome 120, Safari), заменяя стандартный OpenSSL на BoringSSL
- **tls-client** — специализированный клиент для Python, предназначенный для имитации TLS-handshake реальных браузеров, что критично для прохождения проверок на сетевом уровне

#### 4.3. Подмена цифровых отпечатков (Fingerprinting)
- **TLS/JS Fingerprinting**: Использование `curl_cffi` для имитации сетевого стека реальных браузеров (Chrome 120, Firefox 121 и др.)
- **HTTP/2 & HTTP/3 Fingerprinting**: Проверка параметров протокола для согласования с заявленным User-Agent
- **Canvas и WebGL Fingerprinting**: Имитация отрисовки графики браузером через Playwright

#### 4.4. Продвинутая браузерная автоматизация
- **Nodriver**: Использование `nodriver` как альтернативного решения для управления Chrome через протокол CDP
- **Playwright Stealth**: Применение методов обхода обнаружения в Playwright
- **Selenium с stealth настройками**: Расширенные настройки для сокрытия факта автоматизации

#### 4.5. Преодоление активных проверок (Turnstile и капчи)
- **Имитация поведения**: Алгоритмы, имитирующие «человеческий» ввод: кривые Безье для мыши, случайные паузы
- **Managed Services**: Интеграция с `capsolver` для решения криптографических задач Turnstile
- **Behavioral Analysis**: Системы отслеживания движений мыши, скорости прокрутки и интервалов между кликами

#### 4.6. Инфраструктурные методы
- **Поиск Origin IP**: Попытка найти прямой IP-адрес сервера-источника
- **Использование куки cf_clearance**: Стратегия однократного прохождения проверки и повторного использования токенов

### 5. Улучшения в парсинге RTS-Tender
- Добавлена стратегия улучшенного cloudscraper с JA4 TLS fingerprinting
- Реализован многоуровневый подход: сначала улучшенный cloudscraper, затем cookie-based обход, затем nodriver, затем Selenium
- Добавлены улучшенные заголовки и настройки для обхода Anti-DDoS защиты RTS-Tender

### 6. Ускорение процесса сборки
- Добавлен файл `.dockerignore` для исключения ненужных файлов из контекста сборки
- Добавлены оптимизации в `docker-compose.yml`:
  - Добавлена настройка `restart: unless-stopped`
  - Добавлена переменная `PYTHONUNBUFFERED=1` для улучшения логирования

## Быстрая сборка и запуск

Для быстрой сборки и запуска контейнеров выполните:

```bash
# На Linux/Mac:
./build.sh

# На Windows (PowerShell):
docker-compose build --no-cache
docker-compose up -d
```

## Проверка состояния контейнеров

```bash
# Проверить статус контейнеров
docker-compose ps

# Посмотреть логи API сервиса
docker-compose logs -f api

# Посмотреть логи Frontend сервиса
docker-compose logs -f frontend
```

## Преимущества оптимизаций

1. **Более быстрая сборка**: за счет использования `.dockerignore` и оптимизаций в Dockerfile
2. **Избегание интерактивных шагов**: сборка не прерывается на вопросах о часовых поясах и прочих настройках
3. **Улучшенная стабильность**: обработка случаев, когда cloudscraper недоступен
4. **Более быстрая работа с зависимостями**: глобальный импорт ускоряет работу приложения
5. **Улучшенная отказоустойчивость**: добавлены политики перезапуска контейнеров
6. **Улучшенный обход защиты Cloudflare**: особенно для сайтов с усиленной защитой, таких как RTS-Tender
7. **Многоуровневый подход к парсингу**: при неудаче одного метода автоматически используется другой
8. **Современные методы обхода антибот-защиты**: TLS fingerprinting, nodriver, seleniumbase, drissionpage, behavioral analysis
